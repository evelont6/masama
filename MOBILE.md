# Pakai Masama di HP

1. Buka https://evelont6.github.io/masama/ di Chrome atau Safari.
2. Ambil foto struk / pilih galeri, atau pilih **Isi manual**.
3. Periksa hasil scan, edit jika diperlukan, lalu tambah teman dan bagi tagihan.
4. Pilih **Bagikan** atau **Salin** untuk mengirim ringkasan.

Tidak perlu login atau API key. Foto dibaca di perangkat dan tidak diunggah. Unduhan OCR pertama memerlukan internet dan bisa membutuhkan beberapa saat. Scan berikutnya dapat berjalan offline jika file OCR masih ada di cache browser. Input manual, pembagian, dan draft dapat dipakai offline setelah aplikasi selesai dimuat dan tersimpan.

## Pasang sebagai aplikasi

- Android: pilih **Pasang Masama di HP** atau menu Chrome → Instal aplikasi.
- iPhone: Safari → Bagikan → Tambah ke Layar Utama.

Draft dan rekening tersimpan di perangkat. Menghapus data browser menghapus draft. **Mulai split baru** meminta konfirmasi dan tetap menyimpan rekening.

Jika tampilan masih versi lama setelah rilis, tutup semua tab/jendela Masama lalu buka kembali dengan internet. Browser akan memakai pembaruan setelah worker versi lama berhenti.

Pengujian browser mencakup scan struk contoh dengan OCR sungguhan, scan ulang offline, perhitungan, penyimpanan, dan tampilan lebar HP. Instalasi pada perangkat Android/iPhone fisik dan beragam foto struk nyata tetap perlu dicoba.
